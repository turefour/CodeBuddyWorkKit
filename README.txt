CodeBuddy 工作套件 1.0.0
=======================

解压后双击 installer.exe 安装。详细说明见 payload\docs\使用说明.txt。

包含内容
--------
  CodeVault 索引库      项目索引 / 源码查看 / 仓库状态 / 脚本库（Web，默认 47910）
  CodeBuddy Pulse       AI 编程进度看板 + 重复测试进程守护（默认 47821）
  Idle Tuner            IDE 空闲降温面板（默认 47822）
  ScriptVault 脚本库    公共模块 / 可复用工具 / 回归测试 / 项目接入工具
  全局规则              ~\.codebuddy\rules\deploy-target.mdc

安装器功能
----------
  1. 说明功能，用户确认后才开始
  2. 安装前检测环境（PowerShell 版本、Node、目录可写、磁盘、端口占用、已有部署）
  3. 部署完成后自动自检（文件层 + 进程层 + 接口层），全通过才提示「部署完成」
  4. 安装目录内提供「一键清理与回退.cmd」，停止服务并撤销快捷方式与规则

桌面窗口
--------
  桌面快捷方式启动的是独立窗口程序（CodeBuddyWorkKit.Shell.exe），不是浏览器标签页：
    · 无地址栏 / 标签页，自动拉起服务
    · 最小化与关闭都收进右下角托盘，双击恢复
    · 托盘右键：显示窗口 / 打开各面板 / 关闭窗口 / 停止服务并退出
    · 不做开机自启（不写 Run 项、不放启动文件夹）

静默安装（脚本化部署）
--------------------
  installer.exe --silent --target "D:\CodeBuddyWorkKit" --port 47910 --pulse 47821 --tuner 47822
  退出码：0 成功 / 1 检测或自检失败 / 2 参数或环境错误

系统要求
--------
  Windows 10/11（x64）
  .NET Framework 4.x（Win10 自带，安装器依赖）
  Node.js 18+（本包可附带运行时；若附带则无需单独安装）
  Git（可选，用于版本管理；本包可附带便携版）

回退
----
  安装目录\一键清理与回退.cmd
